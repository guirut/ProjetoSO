# Projeto 2 – Uso de Memória e Swap com Abas do Navegador
> Disciplina de Sistemas Operacionais, Universidade Presbiteriana Mackenzie.

**Turma 04P · Grupo CAT6E**

**Pergunta central:** quanto de swap memory custa abrir 50 abas do Google, medido em GB?

A partir dessa pergunta, cada integrante investigou como um componente do dispositivo se comporta conforme aumentam as abas abertas: memória e swap, RAM disponível, processador, placa de vídeo e energia.
